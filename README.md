## Tentang Aplikasi

- Menampilkan website [YamadaVerse](https://www.yamadaverse.xyz) dalam mode aplikasi Android (WebView).
- Fokus pada pengalaman mobile yang ringan, cepat, dan langsung ke konten.
- Navigasi tombol back Android mengikuti riwayat halaman web.
- Nama package Android: `io.yamadaverse`.

## Teknologi

- **Framework**: Flutter
- **Dependency Utama**: `webview_flutter`
- **Minimum SDK**: Android 21 (Lollipop)
